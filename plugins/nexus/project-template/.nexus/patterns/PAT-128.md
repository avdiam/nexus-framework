# PAT-128: boundary-regime-measurement

*Version: 1.0.0 | Date: 2026-06-14 | Sprint: 103*

## Metadata
- **Type**: methodology
- **Status**: active
- **Created**: 2026-06-14

## Problem

When measuring whether an input variable (description form, routing phrasing, prompt wording, a feature flag) affects an LLM's recognition/selection/trigger decision, the natural instinct is to probe with clear, strong example queries. But strong-match queries **saturate**: the decision comes out unanimous regardless of the variable, so the effect you are trying to measure has zero dynamic range and is invisible. A measurement built on saturated probes returns a **null-by-construction** — not evidence that the variable has no effect, but evidence that the instrument could not have detected one.

## Context
- **Use When**: Designing the ground-truth / eval-set queries for an A/B or sensitivity measurement over LLM behavior (does form/phrasing/wording change the model's decision?); measuring trigger, routing, or skill-selection sensitivity to a description change; any experiment where the *delta* attributable to a controlled variable is the quantity of interest.
- **Not When**: Measuring **absolute** accuracy/quality (not sensitivity to a variable) — there, representative real-world queries are exactly right; when the decision is known to be genuinely non-saturated across the natural query distribution.
- **Prerequisites**: You can construct queries at graded match-strength to the target candidate, and you can run clean controls (strong-positive, strong-negative, weak-negative) to prove the instrument discriminates.

## Solution

Place the probe queries at the **recognition boundary** — *weak-match-to-the-target-candidate*, where a marginal match may or may not be recognized — because that is the only regime with the dynamic range to reveal a form/phrasing effect. Avoid both strong-match-to-candidate (saturates to always-yes) **and** strong-match-to-a-sibling (saturates to always-route-away, regardless of the candidate's form).

### Implementation
1. **Model the boundary correctly.** "Boundary" = weak-match-to-the-*candidate under test*, not strong-match-to-a-sibling. A query that strongly fits a competitor routes away unanimously no matter how you vary the candidate — that is null-by-construction, not a boundary probe.
2. **Run controls to validate the instrument.** Strong-positive (should be ~1.0), strong-negative and weak-negative (should be ~0.0). Clean controls prove fractional rates on the boundary probes are real signal, not noise.
3. **Pilot before committing the budget.** Run the boundary design on one subject first; if it still saturates, the boundary was mis-modeled — fix it before scaling (composes with `pilot_before_batch`).
4. **Read saturation as a finding, not a failure** — but only after controls prove the instrument works. A clean-control ceiling means the variable genuinely does not move the decision; a dirty-control ceiling means a broken instrument.

## Rationale

The wisdom: **a variable's effect is only observable where the decision is marginal.** A measurement has dynamic range only in the region where the outcome is not already determined by something other than the variable. Saturated regions — where the answer is unanimous for reasons unrelated to the variable — carry zero information about the variable's effect, so probing there guarantees a null whether or not an effect exists.

- **Theoretical Basis**: Signal detection / dynamic range — sensitivity is measurable only near the decision threshold; far from it, the response is clipped.
- **Empirical Evidence**: ISS-217 (Sprint 103). The first boundary attempt mis-modeled "boundary" as strong-match-to-sibling and produced a saturated null (F8). Reframing to weak-match-to-candidate un-saturated the cells while controls stayed clean (strong-pos=1.0, strong-/weak-neg=0.0), proving the fractional rates were real signal. `pilot_before_batch` caught the mis-design before the full measurement budget was spent.

## Anti-Patterns
- **Anti-Pattern 1**: Probing with clear, strong, "obvious" example queries.
  - **Why Wrong**: They saturate — the decision is unanimous regardless of the variable, so any real effect is clipped to invisibility.
  - **Example**: Measuring whether description *form* changes skill triggering using queries that obviously match the skill — every form triggers, delta = 0, "form doesn't matter" concluded falsely.
- **Anti-Pattern 2**: Mistaking strong-match-to-a-sibling for a boundary probe.
  - **Why Wrong**: Sibling-strong queries route away unanimously independent of the candidate's form — a different saturated regime, equally null-by-construction.
- **Anti-Pattern 3**: Reporting a saturated null as "no effect" without validating the instrument with controls.
  - **Why Wrong**: Cannot distinguish a real ceiling from a broken instrument; the null is uninterpretable.

## Consequences
- **Benefits**: Measurements actually have the dynamic range to detect the effect under study; saturated nulls are distinguished from real nulls via controls; avoids spending a large measurement budget on a design that could only ever return null.
- **Tradeoffs**: Boundary queries are harder to author than obvious examples and require iteration/piloting; needs an explicit control battery.
- **Risks**: Boundary mis-modeling (sibling-strong instead of candidate-weak) silently reintroduces saturation — pilot to catch it.

## Examples

### Before/After Comparison
**Without Pattern**: ISS-217 iter1 — boundary modeled as strong-match-to-sibling → all cells saturated, baseline=variant byte-identical, null-by-construction. Scaling this would have produced expensive null data.
**With Pattern**: iter2 — boundary remodeled as weak-match-to-candidate → cells un-saturated (e.g. 0.75→0.0 under a form change) while controls stayed clean → fractional rates confirmed as real signal, method validated for scale.

## Validation
- **Success Indicator**: Boundary probes return fractional (non-unanimous) rates while strong-positive controls ≈1.0 and negative controls ≈0.0 — the instrument has dynamic range and discriminates.
- **Edge Cases**: If boundary probes still saturate after piloting with clean controls, the effect is genuinely absent in that regime — report the ceiling as the finding (with the control evidence), not as a measurement failure.

## Notes and Observations
Born from the trigger-accuracy research where confirmation-bias discipline was load-bearing: verifying the instrument (clean controls) *before* trusting saturated positives is what separated "real recognition ceiling" from "blanket-yes." The reusable lesson pairs with the reporting calibration: prefer "unsupported" over "refuted" when a null comes from a saturated instrument, and foreground the effective evidence base (movable cells) rather than the raw cell count.
