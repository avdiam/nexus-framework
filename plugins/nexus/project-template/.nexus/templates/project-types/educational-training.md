[Section: Deliverable-Templates]
### MVP Examples
- name: "Learning Objectives & Curriculum Design"
  description: "Structured learning path: objectives per module, sequencing logic, prerequisite mapping"
  quality_criteria: "Objectives are measurable (observable behavior, not 'understand'), sequencing follows dependency logic"
- name: "Core Training Content"
  description: "Primary learning materials: lessons, exercises, examples, practice activities"
  quality_criteria: "Content maps to learning objectives, examples are realistic, exercises reinforce key skills"
- name: "Assessment Framework"
  description: "Methods for measuring whether learners achieved the objectives: quizzes, projects, demonstrations"
  quality_criteria: "Each objective has a corresponding assessment, rubrics are clear, difficulty matches expected level"

### Enhanced Examples
- name: "Instructor / Facilitator Guide"
  description: "Facilitation notes, timing guidance, discussion prompts, common misconceptions to address"
  quality_criteria: "Another instructor could deliver the training effectively using only this guide"
- name: "Learner Support Materials"
  description: "Quick references, cheat sheets, job aids, glossaries for ongoing use after training"
  quality_criteria: "Concise enough for actual use, covers the most common needs"
- name: "Pilot Results & Refinements"
  description: "Findings from testing with real learners: what worked, what confused, what needs revision"
  quality_criteria: "Pilot ran with representative learners, feedback collected systematically, changes documented"

### Future Examples
- name: "Advanced / Elective Modules"
  description: "Deeper content for learners who want to go beyond the core curriculum"
  quality_criteria: "Builds on core without duplicating, clearly marked as optional"
- name: "Certification Program"
  description: "Formal certification with standardized assessment, grading criteria, and credential management"
  quality_criteria: "Assessment is reliable (consistent results), valid (measures what it claims), and fair"

### Categorization Guidance
"MVP = learners can achieve the core competency with assessed proof. Enhanced = the training is deliverable by others and supported with materials. Future = the learning program scales and formalizes."
[/Section: Deliverable-Templates]

[Section: Phase-Templates]
### Simple (2-3 phases)
- phase: "Design & Development"
  objective: "Define learning objectives, create content and assessments, build learning materials"
  typical_deliverables: "Curriculum design, core content, assessment framework"
  milestone: "Complete learning materials ready for pilot testing"
- phase: "Pilot & Refinement"
  objective: "Test with real learners, collect feedback, measure outcomes, refine materials"
  typical_deliverables: "Pilot results, refined content, facilitator guide"
  milestone: "Training validated with learners achieving target competency"

### Standard (3-4 phases)
- phase: "Needs Analysis & Design"
  objective: "Understand learner needs, define objectives, design curriculum structure and assessment approach"
  typical_deliverables: "Learner analysis, learning objectives, curriculum outline, assessment strategy"
  milestone: "Learning objectives defined with clear success criteria"
- phase: "Content Development"
  objective: "Create learning materials, exercises, examples, and assessments"
  typical_deliverables: "Training modules, practice exercises, assessment instruments, support materials"
  milestone: "All content created and internally reviewed"
- phase: "Pilot & Validation"
  objective: "Run training with representative learners, collect data on learning outcomes"
  typical_deliverables: "Pilot delivery, learner feedback, outcome measurements, gap analysis"
  milestone: "Pilot demonstrates learners achieving target objectives"
- phase: "Refinement & Launch"
  objective: "Incorporate pilot feedback, finalize materials, prepare for broader delivery"
  typical_deliverables: "Refined content, instructor guide, learner support materials, delivery plan"
  milestone: "Training ready for full delivery with all materials finalized"

### Complex (5-6 phases)
- phase: "Needs Analysis"
  objective: "Assess current competency gaps, define target audience, understand delivery constraints"
  typical_deliverables: "Competency gap analysis, learner profiles, delivery requirements"
  milestone: "Training need validated with clear target audience and competency goals"
- phase: "Instructional Design"
  objective: "Design curriculum architecture, learning paths, assessment strategy, engagement approach"
  typical_deliverables: "Curriculum blueprint, assessment framework, engagement strategy"
  milestone: "Curriculum design approved by stakeholders and subject matter experts"
- phase: "Content Creation"
  objective: "Develop all learning materials, exercises, assessments, and support resources"
  typical_deliverables: "Training modules, practice labs, assessment instruments, reference materials"
  milestone: "All content created, reviewed by SMEs, and internally tested"
- phase: "Pilot Program"
  objective: "Deliver to a representative cohort, measure outcomes rigorously, identify gaps"
  typical_deliverables: "Pilot delivery, outcome data, learner feedback, facilitator observations"
  milestone: "Pilot data shows target learning outcomes with identified improvements"
- phase: "Iteration & Scale"
  objective: "Refine based on pilot data, develop facilitator resources, prepare for scale"
  typical_deliverables: "Revised content, instructor guide, delivery playbook, train-the-trainer materials"
  milestone: "Training deliverable by other facilitators with consistent quality"
- phase: "Launch & Evaluation"
  objective: "Full deployment, ongoing measurement, continuous improvement framework"
  typical_deliverables: "Full program launch, evaluation framework, improvement cadence"
  milestone: "Program running independently with measurable learning outcomes"

### Phase Naming Guidance
"Use instructional design language: Needs Analysis, Instructional Design, Content Development, Pilot, Validation, Launch. Avoid software terms (Sprint, Deploy) and academic terms (Literature Review)."
[/Section: Phase-Templates]

[Section: Risk-Catalog]
- risk: "Learner engagement drops — content is technically correct but not compelling"
  probability: "Medium"
  impact: "High"
  mitigation_hint: "Use varied formats (examples, exercises, discussion), pilot early to catch engagement issues, design for active learning not passive consumption"
- risk: "Assessments don't measure what they claim — learners pass but can't perform"
  probability: "Medium"
  impact: "High"
  mitigation_hint: "Align assessments to observable behaviors not just knowledge recall, use performance-based assessment where possible"
- risk: "Content becomes outdated quickly in fast-moving domains"
  probability: "Medium"
  impact: "Medium"
  mitigation_hint: "Separate evergreen principles from volatile details, design content for easy updates, plan review cadence"
- risk: "Prerequisite assumptions wrong — learners under- or over-prepared"
  probability: "Medium"
  impact: "Medium"
  mitigation_hint: "Include diagnostic pre-assessment, provide remedial path for under-prepared learners, offer skip-ahead for advanced"
- risk: "Training doesn't transfer to real work — knowledge stays in the classroom"
  probability: "Medium"
  impact: "High"
  mitigation_hint: "Use realistic scenarios and examples from the actual work context, include job aids for post-training reference"
- risk: "Subject matter expert availability constrains content accuracy and review"
  probability: "Medium"
  impact: "Medium"
  mitigation_hint: "Front-load SME time during design phase, batch review sessions, create review-friendly content formats"
[/Section: Risk-Catalog]
